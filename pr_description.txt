💡 **What:** Replaced the array index `i` with unique, stable identifiers from the mapped items (e.g., `item.label`, `s`) as the `key` prop in the `map()` methods inside `DesktopUI.tsx`. For primitive static number array, used a combined index-and-value key to ensure distinctness. Added a vitest benchmark for `DesktopUI`.

🎯 **Why:** Using an array index as a React `key` is an anti-pattern. If the underlying data changes, is reordered, added to, or deleted from, React can get confused when mapping array indices to component state, leading to unnecessary re-renders, performance degradation, and subtle bugs where state gets attached to the wrong component instance. Unique stable identifiers optimize React's reconciliation process.

📊 **Measured Improvement:** We ran vitest benchmark before and after the change for the `DesktopUI` render.
* **Baseline:** ~28.88 hz (operations per second)
* **Improved:** ~31.79 hz
* **Change:** ~10% improvement in rendering frequency rate for the `DesktopUI` component.
